Choose the photographs.

156 options, grouped by the page each one is for. Note the code under any picture you like — for example 03-women-at-work / 07 — and send the list back. Around ten is enough to start.

How to use this page

Three things worth knowing.

Pick by the code

The code sits under every photograph. You do not need to save or send the images themselves — just the codes, in any order, in an email or a message.

These are previews

Every one is shown small and compressed so this page loads quickly on a phone. The versions that go on the site are the full-resolution originals.

Your own photographs beat all of them

If FemmForce has pictures from a real training session, the Ubuntu Consortium day, or any event — send those instead. A real photograph of the actual work is worth more than any of these.
